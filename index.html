routes/web.php 
// RESTful routing with filters, groups, and named routes.
Route::group(['prefix' => '/api', 'filter' => 'auth'], function () {
    Route::get('/posts', [PostController::class, 'index']);
    Route::post('/posts', [PostController::class, 'store'])
        ->filter('validate:PostRequest');
});

// Controllers stay thin — business logic lives where it belongs.
class PostController extends Controller {
    public function store($request) {
        $post = Post::create($request->validated());
        return response()->json($post, 201);
    }
}

    ->orderBy('created_at', 'desc')
    ->limit(10)
    ->get();

// Eager load to kill the N+1 problem.
$posts = Post::with(['author', 'tags'])->paginate(15);

// Collections make transforming data fluent.
$titles = $posts->map(fn ($p) => $p->title);

// Transactions, scopes, and relations — all built in.
DB::transaction(fn () => Order::create($data));
// Row-level multi-tenancy — automatic, no boilerplate.
class Document extends Model {
    use TenantScoped;  // auto-filter + auto-assign
}

// Resolve the tenant from the subdomain, set the context once.
$tenant = Tenant::resolveFromSubdomain($request);
Tenant::set($tenant->id);

// Every query is now scoped. Every insert is now tagged.
$docs = Document::where('status', 'draft')->get();
Document::create(['title' => 'Q3 report']); // tenant_id auto-set

// Need isolated databases per tenant? That's supported too.
Tenant::connection($tenant->id)->run(fn () => Invoice::all());

// Ask a question, get a structured answer.

SaaS-ready out of the box

Multi-tenancy without the engineering marathon

Building a multi-tenant product usually means weeks of plumbing. Lightpack ships three battle-tested strategies so you pick the right one for your workload and move on.

  • Database-per-tenant — full isolation for regulated industries.
  • Schema-per-tenant — balance of isolation and overhead.
  • Row-level tenancy — shared tables with automatic scoping. Zero boilerplate.
  • Automatic query filtering and automatic tenant assignment on every insert.
  • Flexible tenant resolution: subdomain, session, or JWT/token-based.
Read the multi-tenancy guide →
app/Models/Document.php 
class Document extends Model {
    use TenantScoped;
}

// Middleware resolves tenant once per request.
Tenant::set($request->tenant->id);

// That's it. Queries are scoped. Inserts are tagged.
$docs = Document::latest()->take(20)->get();
AI, first-class

Add AI features without adopting a second framework

Lightpack's AI service gives you a single, provider-agnostic API for chat, streaming, embeddings, multimodal input, and agentic tool use — right inside the app you already know.

A deployment suite, not a wiki page of shell commands

Lightpack's deployment tooling provisions your server, configures the environment, deploys the app, wires up the domain, enables HTTPS, and lets you roll back in one command.

  • Server provisioning and app deployment in a single workflow.
