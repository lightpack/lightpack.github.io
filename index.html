The Promise

Four things that never change.

Lightpack stays simple. Stays fast. Stays stable. Stays free. Not as a marketing claim — as a design principle.

01

Stays Simple

No facades. No magic methods. No auto-discovery. What you see is what it does. When you trace a request, you can follow it from route to controller to response without jumping through service providers, middleware stacks, and reflection-based resolution.

File-based config. Explicit route definitions. No annotation parsing.
02

Stays Fast

Boot time under 5ms. Memory footprint under 2MB. Lightpack doesn't load what you don't use. No service provider booting 40 bindings on every request. No global middleware chain that runs even for your API routes.

Benchmark: 5ms boot / 2MB RAM / 12,000+ req/s on a single core
03

Stays Stable

No breaking changes on upgrade. Your code from v0.1 still runs on v0.x. Lightpack evolves by adding, not by replacing. When a better approach is found, the old one stays documented and supported — not deprecated and removed in the next major.

Every release is backward compatible. No upgrade guides. No migration scripts.
04

Stays Free

Open source. No paid tiers. No freemium model. No "community edition" with the good features locked behind a license. Everything — including deployment — is free. Free means free.

MIT licensed. No paid add-ons. No commercial upsell. Ever.

The Philosophy

What you see is what it does.

No facades. No magic methods. No auto-discovery. When you trace a request, you can follow it — line by line — from route to controller to response.

The pattern you're used to

magic.php
// Where does this come from?
$user = User::find($id);

// What does this resolve to?
Cache::get('key');

// Which provider handles this?
event(new UserRegistered($user));

// 5 files deep to find out.

The Lightpack way

explicit.php
// You know exactly where this goes
$user = new UserModel();
$user = $user->find($id);

// You know exactly what this does
$cache = new Cache(new FileDriver());
$value = $cache->get('key');

// You know exactly who handles it
event()->dispatch(
    new UserRegistered($user),
    [UserRegisteredListener::class]
);

Explicit doesn't mean verbose. It means you can read your code and know what it does — without opening 5 files, without checking a service provider, without wondering what a facade resolves to at runtime.
